astres

The solar system drawn as ridgeline graphs, in your browser.
Ten solid worlds from real elevation data, the Sun from magnetic field measurements.
Rust → WebAssembly + WebGPU. No server, no API key.
(/!\ clicking and zooming in on all bodies will result in downloading ~1 GB of data.)

WebGPU required.
Try Chrome 113+ or Safari 18+.

Drag to orbit · right-drag to pitch and turn · wheel to change altitude · click a sky marker to jump to that body · zoom all the way out to see the system.

Each body is a globe of stacked constant-latitude rings, every ring an elevation profile sweeping longitude. Elevation data from NASA / USGS / NOAA / DLR, hosted as a Hugging Face dataset and streamed coarse-to-fine. Geometry is generated per frame in a WebGPU compute pass, source. More detail in About astres.
