kNN weather

Inverse-distance-weighted kNN estimate of live weather at any point on Earth,
computed from the k nearest METAR stations. Runs client-side: haversine distance over ~8,100 stations, live observations fetched directly from the source APIs.

INPUT

OUTPUT

neighbours

# ICAO name country elev (m) dist (km) temp (°C) dewpoint (°C) wind (m/s) dir (°) pres (hPa) obs (UTC) source

calculation

For each variable: inverse-distance-weighted estimate over the neighbours above that reported a value, weight = 1/distance (sklearn KNeighborsRegressor(weights='distance') convention — not 1/d²; see idw.js). Missing values are skipped, never zero-filled.

model at point (not an observation)

PERFORMANCE

Station list: NCAR/RAP stations.txt (Greg Thompson, NCAR/RAP), ~8,100 METAR-reporting stations.
Observations: Iowa Environmental Mesonet (global ASOS/METAR currents), api.weather.gov (US stations), Open-Meteo (gridded forecast model, sampled at the point — not a station observation).
kNN / IDW method from SenseAI's weather tools (2015), where TC was CTO: BallTree(haversine) + sklearn KNeighborsRegressor, re-implemented here in plain JS.
