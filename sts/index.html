speech-to-speech

Full-duplex voice-to-voice in your browser.
Rust → WebAssembly + WebGPU. No server, no API key.
Your audio never leaves your machine.

model will be stored locally: ~3.8 GB

download is off for now. the demo is not ready for visitors.

what runs. PersonaPlex-7B pruned to 24 layers and recovered with QLoRA, Q4_K, on Burn's wgpu backend in WebAssembly. mic → Mimi encoder → temporal and depth transformers → Mimi decoder → speaker. all in the tab.

what it does. walkie-talkie turns, a few voice presets. it answers. slowly: about 3× slower than realtime on a consumer GPU, so you talk, wait, listen. audio quality is rough.

what it doesn't do yet. full duplex. the model is built for it; the streaming path isn't wired in.

next. wire the duplex path, then speed. a smaller checkpoint would help both.

Quantized, pruned PersonaPlex-7B (24 layers, QLoRA-recovered) model (Mimi audio codec + temporal/depth transformers), custom Rust inference compiled to WebAssembly, GPU acceleration via WebGPU.
