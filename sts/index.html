Can you run speech-to-speech in the browser? Almost.

Full-duplex voice-to-voice, entirely client-side: microphone in, model reasons over audio, speech out, no server round-trip. This is where that experiment currently stands.

What runs today

A Q4_K-quantized PersonaPlex-7B — a 24-layer pruned + QLoRA recovery variant — running on Burn's wgpu backend, compiled to WebAssembly. The pipeline runs end-to-end in Chrome/Edge with WebGPU: 

Microphone → AudioWorklet (24kHz mono) → Mimi encoder (WASM)
  → Temporal transformer (WASM/WebGPU) → Depth transformer (WASM/WebGPU)
  → Mimi decoder (WASM) → AudioWorklet playback

Walkie-talkie mode is functional, with a handful of voice presets available.

What's broken

Audio quality is poor, and generation runs roughly 3x slower than realtime on consumer GPUs — turn-based, not true full-duplex, for now. WebGPU is required, which means Chrome 113+ or Edge 113+ over HTTPS; there is no fallback path for browsers or devices without it.

Coming soon

True duplex streaming, and further perf work once there's a smaller checkpoint to build on.
